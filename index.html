Flight Tracker

A live flight-tracking web app, self-hosted on a home NAS. It tracks global air traffic in real time, plotting live aircraft positions worldwide on an interactive map using data from the OpenSky Network. Stack: Spring Boot (Java) backend split into an API service and a polling agent, a React + TypeScript + Leaflet frontend, PostgreSQL, and Docker Compose for deployment.
