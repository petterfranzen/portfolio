02 Operating model

A task enters.
Six steps later it ships.

The same loop every night, run by agents that don't get tired and don't skip the tests.

  1. 01

    Intake

    the brief

    A task lands with a definition of done and a deadline.

  2. 02

    Engineering

    Batou

    Builds it. Small commits, tests before the push, no exceptions.

  3. 03

    Research

    Ishikawa

    Reads the docs and the previous nights so the next attempt isn't a repeat.

  4. 04

    Architecture & review

    Saito

    Checks the shape of it: boundaries, failure modes, whether it belongs at all.

  5. 05

    QA

    Togusa

    Drives it like a stranger would: on a phone, with the network off.

  6. 06

    Ship

    published

    Merged, published, logged. Then the next task enters.
