Projects

Flight Tracker

Live global flight tracking. An always-on sweep keeps a position history current for every aircraft worldwide while a faster poll follows whatever's actually on screen, so the map stays live without pulling the whole world at once. Every position is kept for 72 hours, which is what lets it derive distance flown and airborne hours for any window straight from that history, with no separate usage table to keep in sync.

Stack: Java 21 / Spring Boot in a single process: REST, WebSocket and the pollers in one JVM, with SQLite in WAL mode and a Vanilla TypeScript + MapLibre GL frontend.

Live flight.pastabake.cloud ↗

Docker Monitor

A small service that watches every container on my home NAS and pushes an alert when one breaks: stopped unexpectedly, restart-looping, failing its healthcheck, gone quiet, or suddenly spiking. The same service exposes a small API that starts, stops and updates the Compose projects it has been told it may control, which is what the demo buttons in The Lab below talk to.

Stack: Python 3 with the Docker SDK, FastAPI + uvicorn for the control API, and ntfy for the notifications. No build step.
